# Distro logos

Every logo is trimmed and centred on the same transparent 256x256 square so they all share one ratio.

- The original 15 come from the Know Your Distro game (https://github.com/akashanil-dev/know-your-distro).
  Manjaro uses the Papirus version instead, because the original file didn't survive trimming.
- Linux Mint, Pop!_OS, MX Linux, Zorin OS, Raspberry Pi OS, Deepin, BlackArch, ArcoLinux, Artix, SteamOS,
  Absolute Linux, Calculate Linux and Manjaro come from the Papirus icon theme
  (https://github.com/PapirusDevelopmentTeam/papirus-icon-theme, GPL-3.0).
- elementary OS, Kubuntu, Rocky Linux, Oracle Linux and Tails come from Simple Icons
  (https://simpleicons.org, CC0 1.0), filled with each project's brand colour.

The logos are trademarks of their respective projects and are used only to identify them in an
educational game.
