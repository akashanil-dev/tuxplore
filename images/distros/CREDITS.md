# Distro logos

Every logo is trimmed and centred on the same transparent 256x256 square so they all share one ratio.

- These come from the Know Your Distro game (https://github.com/akashanil-dev/know-your-distro).
  Manjaro uses the Papirus version instead (https://github.com/PapirusDevelopmentTeam/papirus-icon-theme,
  GPL-3.0), because the original file didn't survive trimming.

The logos are trademarks of their respective projects and are used only to identify them in an
educational game.
