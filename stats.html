What we collect

When TuxOS runs, it can send these events to its own server. The server only adds one to that day's count for the event, and stores nothing else.

Page views are counted by GoatCounter, an open-source analytics service that uses no cookies. Its numbers are public too: tuxplore.goatcounter.com.

Nothing is sent if you turn off "Share anonymous usage counts" in TuxOS Settings, or if your browser asks sites not to track you (Do Not Track or Global Privacy Control).

The code for all of this is open: github.com/akashanil-dev/tuxplore (see js/analytics.js and api/src/index.js).
